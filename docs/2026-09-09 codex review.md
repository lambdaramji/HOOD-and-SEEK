활성 문서 [기기 조사와 비전 실측](../inbox/김병직/2026-08-30-device-survey-and-vision-test.md)은 배포받은 개발 문서에 기밀 표기가 있다고 기록한다. #16은 PDF 86개의 변환본 43개를 `docs/markdown/`에 추가하므로, “기밀 표기가 있는 자료의 원문을 옮기지 않는다”는 `CLAUDE.md` 규칙과 충돌한다.

**판정:** 현재 PR은 닫는다. 필요한 원문은 Git 밖 `REF/LG/`에서 관리하고, 저장소에는 문서명·절과 승인된 결론만 남긴다.

### #19 · ARC 순환 gate

#19는 ARC 전체를 역할 재배치 승인 뒤 시작하게 하지만, #18·#21은 ARC-001 계열 실측을 승인 전제조건으로 둔다. 그대로 합치면 승인 전에는 시험할 수 없고 시험 전에는 승인할 수 없다.

**판정:** 다음 단계로 분리한다.

1. 승인 전 검증: Dart Linux ARM64 독립 실행, ESP32 Pi4 연결 가능성·3초 fail-safe, MLX90640/SPS30 동시 polling, 권장 비전 경로 재측정
2. 승인 후 구현: broker·gateway 이설, 계약 v2와 소비자 전환
3. 최종 승인: 단선 주입·복구·롤백 통합 검증

### #22 · 잘못된 시험 판정과 명령

x86_64 컨테이너에 Pi 장치와 Dart가 없었던 것은 대상 시스템 실패가 아니라 잘못된 실행 환경으로 인한 미실행이다. Dart 공식 도구 기준으로 `aot-snapshot`은 runtime을 포함하지 않으며 `dartaotruntime`이 필요하다. 독립 배포 명제를 검증하려면 빌드 호스트에서 다음과 같이 Linux ARM64 실행 파일을 만들고 Pi4에서 직접 실행해야 한다.

```bash
dart compile exe \
  --target-os=linux \
  --target-arch=arm64 \
  pi5_gateway/bin/hood_seek_gateway.dart \
  -o hood-seek-safety-arm64
```

**판정:** raw 환경 진단은 `inbox/정정인/`으로 옮기고 `[실측]`으로 표시한다. 결과는 `판정 불가/미실행`으로 기록한다.
