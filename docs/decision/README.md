# 의사결정 문서

팀 승인이 필요한 변경을 한 건씩 문서로 남기는 곳이다. 회의에서 구두로 정하고 흘려보내는 대신, **선택지·근거·결정권자·결정 결과**를 파일로 남긴다.

## 대장과의 관계

- [`docs/ai-integration-decisions.md`](../ai-integration-decisions.md)는 **색인**이다. `P-00x`(미결)와 `D-00x`(확정)를 한 줄씩 표로 관리한다.
- 이 폴더는 **본문**이다. 논의가 길거나 선택지 비교가 필요한 항목만 별도 문서로 쓴다.

표 한 줄로 충분한 항목은 문서를 만들지 않는다. 대장에만 남긴다.

## 파일명

```text
P-00x-topic.md
```

새 문서는 [`TEMPLATE.md`](TEMPLATE.md)를 복사해 시작합니다. 짧은 결정은 문서 없이 GitHub 이슈의 "의사결정 요청" 템플릿으로 끝내고, 결과만 대장에 한 줄 남깁니다.

확정되어 `D-00x`가 되어도 **파일명은 바꾸지 않는다.** 링크가 깨진다. 문서 안의 상태만 바꾼다.

## 문서 구조

머리말에 상태와 결정권자를 적고, 마지막에 **결정 기록** 표를 둔다. 팀원은 그 표에 직접 의견과 날짜를 채운다.

| 상태 | 뜻 |
|---|---|
| `제안` | 작성자가 올렸고 아직 논의 전 |
| `논의 중` | 회의 안건으로 올라감 |
| `확정` | 결정권자 승인 완료. 대장의 `D-00x`로 이관 |
| `보류` | 선행 조건이 풀릴 때까지 중단. 조건을 명시할 것 |
