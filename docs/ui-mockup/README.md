# UI 목업

`v1/` — 2026-10-24 사용자 디스플레이 UI v1 (ThinQ 스타일, 1920×1080). 기준 문서는 [`../2026-10-24-flutter-ui-design-v1.md`](../2026-10-24-flutter-ui-design-v1.md), 구현 이슈는 #112.

- `index.html`을 브라우저로 열면 화면 19장 썸네일이 나오고, 카드를 누르면 실제 크기로 열린다. 애니메이션은 CSS라 그대로 움직인다.
- 각 화면은 단독 파일이다. 레이아웃 값(여백·크기·색)은 전부 인라인 스타일이라 Flutter로 옮길 때 그대로 읽으면 된다. 공통 모션 규칙은 각 파일 `<style>`의 `hs-*`.
- `fonts/`·`images/`는 README만 있다. LG EI 글꼴과 LG 그라디언트는 브랜드 에셋이라 저장소에 넣지 않는다(R-16·P-010) — PM이 팀 채팅으로 전달한 zip에서 복사해 넣으면 적용되고, 없으면 Noto Sans KR·CSS 그라디언트로 대체된다.
- 편집 원본은 Claude Design 캔버스(PM 보관). 10/24 PR #113 리뷰 반영(수증기 삭제·해제 조건·기기 시트·센서 탭·카메라 칩)은 HTML을 직접 고쳤으므로 캔버스보다 HTML이 최신이다. 수정 요청은 #112 댓글로.
