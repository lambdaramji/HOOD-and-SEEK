## 기록 원칙

이 문서는 저장소에 남은 실측 로그·소스·사진만 `확인`으로 표시한다. 제품 라벨, 실제 USB/I2C 포트, 전원 어댑터 라벨 또는 배선 사진이 없는 항목은 **미확인**이며, 설계상 연결 방향은 실제 연결 완료를 뜻하지 않는다. 사진을 추정 그림이나 인터넷 제품 사진으로 대체하지 않는다.

### 사진 증거 수집 규격

각 사진은 촬영일·촬영자·파일 경로를 아래 표에 적고, 흐릿한 라벨은 별도 근접 사진을 추가한다. 전원이 켜진 채로 배선을 바꾸거나 노출된 전원 단자를 촬영하기 위해 보호 장치를 해제하지 않는다.

| 사진 ID | 반드시 보일 대상 | 현재 파일 | 상태 |
|---|---|---|---|
| HW-01 | Pi4 모델 라벨, 연결된 I2C 헤더와 전원 입력 | — | 미제출 |
| HW-02 | Pi5 모델 라벨, 카메라 USB 케이블과 전원 입력 | — | 미제출 |
| HW-03 | ESP32 보드 라벨, USB serial 케이블, GPIO26 배선 | — | 미제출 |
| HW-04 | MLX90640·SPS30·DS3231 각 보드의 앞·뒤 라벨과 I2C 배선 | — | 미제출 |
| HW-05 | 팬 라벨, 외부 전원 어댑터 라벨, MOSFET, 공통 GND | — | 미제출 |
| HW-06 | 최종 카메라 프레임과 조리면 ROI 표식·기준 온도계 위치 | — | 미제출 |

사진 파일은 제출 후 `docs/assets/hardware/`에 원본 또는 판독 가능한 축소본으로 추가하고, 이 표의 `현재 파일`을 상대 경로로 갱신한다. 사진에 MAC 주소·Wi-Fi 비밀번호·사람 얼굴이 보이면 공개 전 가린다.

## 배선표: 확인 전에는 연결하지 않는다

| 경계 | 설계상 종단 | 현장 확인 항목 | 사진 | 판정 |
|---|---|---|---|---|
| Pi4 ↔ MLX90640 | Pi4 I2C ↔ MLX90640 I2C | 핀 번호, VCC, GND, SDA/SCL, 주소 스캔, pull-up 중복 | HW-01, HW-04 | 미확인 |
| Pi4 ↔ SPS30 | Pi4 I2C ↔ SPS30 I2C mode | I2C mode, 핀, VCC, GND, 주소 스캔, pull-up 중복 | HW-01, HW-04 | 미확인 |
| Pi4 ↔ DS3231 | Pi4 I2C ↔ DS3231 I2C | 핀, VCC, GND, 주소, 배터리 극성, hwclock | HW-01, HW-04 | 미확인 |
| Pi5 ↔ 카메라 | Pi5 USB ↔ HD-3000 | 실제 USB 물리 포트, 고정, 640×480 캡처 | HW-02 | 장치·캡처 확인 / 물리 포트 미기록 |
| 안전 gateway ↔ ESP32 | Pi4 또는 Pi5 USB ↔ ESP32 USB CDC | P-009 결정 뒤 연결 보드, 실 포트, 115200, `FAN 0..3` ACK, 3초 fail-safe | HW-03 | 미확인 |
| ESP32 ↔ MOSFET ↔ 팬 | GPIO26 → IRLZ44N → 팬 | GPIO26, pulldown, 공통 GND, 팬 극성·정격, 기동 전류, 발열 | HW-03, HW-05 | 미확인 |
| 팬 외부 전원 | 외부 5V → 팬/MOSFET | 어댑터 라벨, 정격 ≥ 기동 전류, 극성, 보호 | HW-05 | 미확인 |

### 정인 확인 순서와 합격 조건

1. **무전원 연속성 확인:** 각 GND·SDA·SCL·GPIO26·팬 극성과 의도하지 않은 단락을 확인한다.
2. **I2C를 한 장치씩 추가:** 버스를 기록하고, 추가할 때마다 기존 장치가 응답하는지 확인한다.
3. **RTC 시간:** DS3231과 Pi5 LAN 시간을 같은 UTC 로그로 남기고 gateway의 과거 5초·미래 2초 제한과 대조한다.
4. **USB serial:** P-009가 확정되지 않았으므로 ESP32 USB를 Pi4 또는 Pi5에 고정하지 않는다. 시험 연결 시 식별과 `FAN 0`~`FAN 3` ACK, 3초 fail-safe만 기록한다.
5. **팬 전력:** 외부 5V만 쓰고 ESP32 USB로 팬을 공급하지 않는다.

## 조리면 ROI와 기준 온도계 위치

현재 저장소에는 최종 카메라 높이·각도, 인덕션 외곽, MLX90640 장착 위치 또는 실장 사진이 없다. 픽셀 좌표나 온도 임계값을 사실처럼 선기록하지 않는다.

| 항목 | 이번 측정의 고정 정의 | 측정 전 기록할 실제 값 |
|---|---|---|
| 카메라 ROI | 실제 인덕션 조리면 외곽 polygon. 후드·반사·손잡이 제외 | 해상도, 꼭짓점, 높이·각도, HW-06 |
| MLX90640 ROI | 같은 조리면을 보는 32×24 셀 집합 | 셀 마스크, 설치 위치·각도 |
| 기준 온도계 | ROI 대표 셀에 가장 가까운 동일 평면, 시야 비차단 | 모델·교정, 위치 사진 |

임시 거치대에서 카메라가 180도 뒤집혀 있었다. `--rotate 180`은 그 거치대 값이다. 최종 브래킷에서 raw 프레임으로 다시 확인한다. [V4L2 라이브](../inbox/김병직/2026-09-20-vision-node-v4l2-fix-and-live-test.md)

## SPS30 조건별 측정 절차 — 현지 임계값 승인용

이 절차는 **임계값을 승인하는 실험 계획**이며, 현재 코드의 데모 기본값(온도 55/70/90°C, PM2.5 35/80/150)을 승인하거나 변경하지 않는다.

| 항목 | 절차 |
|---|---|
| 설치 | 최종 배선·ROI에 고정. 창문/문, 후드 풍량, 인덕션 출력, 온습도, 재료를 기록 |
| 시작 기준 | 자극 없이 안정된 구간을 기록. 안정 시간은 가정하지 않음 |
| 표본 | snapshot UTC, 원시 PM2.5, MLX ROI, 기준 온도계, 팬 단계, 조건 시각을 같은 행에 |
| 반복·복구 | 조건마다 최소 3회. 다음 조건 전 정상 공기 복구 로그 |
| 안전 | 실제 조리 이외의 연소물로 연기를 만들지 않음. 자극·경보 시 중단 |

| 조건 | 재현 방법 |
|---|---|
| 정상 공기 | 조리·가습·증기 없이 유지 |
| 조리 연기 | 현장 규정 안 실제 조리. 의도적 과열·연소 금지 |
| 수증기 | 재료·기름 없이 물만 끓임 |
| 가습기 | 조리면 밖 고정 위치. 센서에 직접 분사하지 않음 |

승인을 받기 전에는 결과를 `demo` 또는 `측정 중`으로만 표기한다.
