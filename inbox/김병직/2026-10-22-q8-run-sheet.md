## 5. 측정 (19:00~19:35)

명령마다 마지막에 한 줄이 나온다. 예: `30 frames | cat - | dog 0.812 | teddy bear - | person -` (`-` = 0.10 이상 검출 없음) [문서 `vision_node/tools/measure.sh`].
같은 조건을 다시 잴 때는 id 뒤에 `b`를 붙인다(예: `d01b`). 같은 id는 거부된다.

### A. 빈 장면 (사람·인형 모두 화면 밖)

```bash
vision_node/tools/measure.sh n01 negative empty - none
```

- 기대: 모두 `-`에 가깝다. [실측 2026-10-20] 빈 화면 person 0/30
- `person`이 0.35 이상이면 화면에 사람이 있는지 도우미가 확인하고 `n01b`로 다시 잰다

### B. 인형 (사람은 화면 밖)

인형만 옮기고 한 줄씩 실행한다. 왼쪽·오른쪽은 **카메라 화면 기준**이다. 박스 앞에 선 사용자에게는 반대다(화면 왼쪽 = 사용자 오른쪽).

「가장자리」는 **몸통 가운데를 테이프 선 위에 두고 눈이 보이게** 놓는 자리다. 처음 정의(「몸통 전체가 조리면 안 + 한 변이 테이프에 닿게」)는 인형(30 cm)이 LED 판(16 cm)보다 커서 놓을 수 없었다. 그래서 10/23에 바꿨다 [실측 10/23 17:36~17:58 사전 시험, #65 정의 변경 댓글, PM 확인]. 눈이 안 보이게 놓이면 같은 자리를 `b`로 다시 잰다(10/23 d05 → d05b).

| d02 | 먼 쪽(화면 위쪽) 테이프 선 위 | `vision_node/tools/measure.sh d02 doll edge_top - true` |

- 기대(가운데): 원래 모델은 `dog` 0.7 안팎 [실측 2026-10-20: `dog` 15/15, 0.75–0.82], v3b는 `cat` 0.93–0.95 [실측 10/24 d01]
- `cat`·`dog`가 모두 `-`이면 얼굴이 카메라 쪽인지 고쳐 놓고 같은 위치를 `b`로 다시 잰다
- d05(카메라 쪽 끝): 원래 모델은 반려동물 칸 0/30에 가짜 `person` 30/30이었다. v3b는 `cat` 0.93~0.95 hit 30/30, `person` 0이다 [실측 10/23·10/24, #65 댓글]
- 먼 쪽 가장자리(d02)는 옛 ROI `bc22a6a7…`에서 겹침이 바깥(d06·d07)과 범위가 겹쳐 지금 판정값으로 잠금 후보가 안 됐다 [#111 PM 결정 4]. PR #123 ROI `b3eda292…`(한 칸 넓힘)에서는 d02가 겹침 0.39로 hit 30/30이고, 먼 쪽 바깥(d08)도 겹침 0.28~0.29로 hit 30/30이다. 바깥 왼쪽·오른쪽(d06·d07)은 0.21·0.24로 hit 0이다 [실측 10/25 01시대 Pi 5 v3e, PR #124 v3e 문서]. ROI +1칸은 PM(현지)이 요청했고 화면을 보고 승인했으니 [병직 전달], 먼 쪽 바깥이 잠기는 것은 그 결과다. M9는 인형을 조리면 가운데에 둔다 [#111 PM 결정 4]

### C. 반사 (사람은 카메라 화면 밖, 박스 바로 옆)

#65 Q8의 「사람이 옆에 섰을 때 조리면 안 person 상자」다. vision-node는 프레임마다 클래스별 최고 후보 1개만 기록한다 [문서 `vision_node/src/main.cpp` `record`]. 그래서 사람이 화면에 있으면 그보다 점수가 낮은 반사 상자는 남지 않는다. 반사는 사람이 화면 밖에 있는 이 조건에서만 잴 수 있다.

1. 도우미가 박스 왼쪽 옆(화면 기준)에 선다. 병직이 화면을 보며 도우미 몸이 안 보이는 자리를 찾는다(창에서 `q`로 닫음).
   ```bash
   python3 vision_node/tools/live_view.py --pi5 $PI5 --roi vision_node/config/roi.json
   ```
2. 창을 닫고, 도우미는 그 자리에 그대로 선 채로:
   ```bash
   FRAMES=30 DUMP_EVERY=15 vision_node/tools/measure.sh r01 negative reflect_left - none
   ```
3. 오른쪽 옆에서 1~2를 반복하고 아래로 잰다.
   ```bash
   FRAMES=30 DUMP_EVERY=15 vision_node/tools/measure.sh r02 negative reflect_right - none
   ```

- `person`이 `-`이면 반사가 사람으로 잡히지 않은 것이다. 숫자가 나오면 그 상자가 가짜 사람으로 표에 들어간다
- 10/23에는 왼쪽 옆에 선 도우미가 유리에 비치지 않아 오른쪽(r02)만 쟀다. 처음 r01은 도우미가 박스 앞에 선 채로 찍혀 무효로 뺐다 [실측 10/23]

**반려동물 칸 → Core state (#64 §3, 1분).** 서비스를 다시 켠 직후에는 `presence=unknown`이다. 고양이 잠금 후보는 vision이 신선해진 뒤 사람이 `P_cat_absent_s`(5.0 s, D-065 — 그 전 4.4 s) 동안 안 보여야(고양이 감시) 된다. `presence=absent`(`P_absent_s` 30 s)와는 따로 센다 [문서 설계서 §3.4, `profiles/default.json`, #168 D-060, #174].
