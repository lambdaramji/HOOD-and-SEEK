# Inbox

`inbox/`는 팀원이 수집·정리한 원문과 작업 메모를 한곳에 모아 사람과 AI가 프로젝트 콘텍스트를 빠르게 파악하도록 돕는 공간입니다.

## 구조

```text
inbox/
├── 남현지/
├── 임재범/
├── 정정인/
├── 이수현/
├── 김병직/
└── archive/      # 사용 완료·대체 원문, 에이전트 기본 탐색 제외
```

개인 폴더에는 본인이 조사하거나 결정한 내용을 올립니다. 여러 사람의 자료를 합친 현재 합의는 [S3~S10 설계서](../docs/2026-10-19-s3-s10-design-v0.1.md)와 [결정 대장](../docs/ai-integration-decisions.md)에 반영합니다. 이전 주제별 통합 문서는 `archive/category/`에 보존합니다(2026-10-19).

## 작성 규칙

1. 파일명은 `YYYY-MM-DD-topic.md` 형식을 권장합니다.
2. 문서 첫 부분에 작성자, 작성일, 상태와 관련 카테고리를 적습니다.
3. 확정 사실, 결정, 가정, 미확인 항목을 구분합니다.
4. 데이터시트·회의록·이슈 등 근거가 있으면 링크나 파일 경로를 남깁니다.
5. 비밀번호, API 키, 개인정보와 공개할 수 없는 원문은 올리지 않습니다.
6. 내용이 활성 기준 문서에 완전히 반영되면 삭제하지 않고 `archive/`로 이동합니다.

## 문서 예시

```markdown
# 문서 제목

- 작성자: 임재범
- 작성일: 2026-08-29
- 상태: draft | verified | deprecated
- 카테고리: flutter-ui
- 관련 이슈/PR: #번호 또는 링크

## 요약

AI나 처음 읽는 팀원이 바로 이해할 수 있는 결론을 적습니다.

## 확인된 사실

- 근거와 함께 확인된 내용을 적습니다.

## 결정 사항

- 무엇을 왜 결정했는지 적습니다.

## 미확인 사항

- 추가 확인이 필요한 내용과 담당자를 적습니다.

## 근거

- 데이터시트, 실험 결과, 회의록 또는 관련 파일 링크
```

AI는 [S3~S10 설계서](../docs/2026-10-19-s3-s10-design-v0.1.md)와 [결정 대장](../docs/ai-integration-decisions.md)을 먼저 읽고, 세부 근거나 최신 작업 과정이 필요할 때 활성 개인 폴더를 확인합니다. 사용자가 별도로 요청하지 않는 한 `inbox/archive/**`는 목록 조회·검색·열람하지 않습니다. 문서가 충돌하면 상태가 `verified`인 최신 활성 문서와 실제 코드를 우선합니다.
