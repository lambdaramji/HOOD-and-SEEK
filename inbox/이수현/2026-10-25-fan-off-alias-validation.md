## 변경과 결론

호출어와 전체 문장이 검증된 `팬거`·`펜거`·`팬 거`·`펜 거`·`펜꺼`·`펜 꺼`를 FAN_OFF로 받는다. 기존 공백·펜→팬 정규화를 재사용하고, 부정·허가/상태 질문·인용·복합 검사 뒤 전체 팬 끄기 문장만 수용한다. `거`를 다른 대상이나 문장 안에서 일괄 치환하지 않는다. 끝 물음표는 기존 PM 정책을 유지한다.

이번 수정의 핵심 근거는 **같은 실발화25건의 원본 전사에서 지원 표현 누락을 보완하면19/25→21/25(84%), 팬 끄기는3/5→5/5로 회복된다는 것**이다. 팬 끄기 두 발화는 기존 규칙이 받아들이지 못했던 경우이며, 이번 비교에서 음원·ASR 전사·정답 intent/value는 바꾸지 않았다. 발화 자체가 틀렸다고 처리하거나 정답 레이블을 바꾼 결과가 아니다.

이21/25를 원본에 대한 규칙 수정 후 정정 평가로 제출한다. 그 두 건이 수정 전 현장에서도 실행됐다고 소급 기록하지는 않는다. 이후 별도 ASR 재전사에서 얻은 WAV→Core20/25와 실시간 재생18/25는 입력/구간 처리 조건이 다른 추가 검증이며, 동일 전사에서 확인한 파서 개선을 취소하거나 대체하는 수치가 아니다. 다만 서로 다른 시험의 장점을 합쳐 공식 NFR-08 통과를 선언하지도 않는다.

## 핵심 정정 평가와 추가 시험의 범위

|시험|정답 intent/value|정답·실제 Core 수락|구분|
|---|---:|---:|---|
|수정 전 새 실시간25회|19/25|19/25|source d9f08b8, 최초 시도 각1개. 원음 끝 지연 검수 전 집계|
|위25개 전사를 수정 파서로 재판정|21/25|미검증|ASR 재실행·재송신 없음. 팬 끄기3/5→5/5|
|문항 클립+무음 실시간 재생|17/25|미검증|문항 사이 배경/문맥을 바꾼 비교 시험, 발행 끔|

수정 전 실시간25회의 설정은 화자 남현지·거리 입력150cm다. 팬 꺼짐은 시작 조건이며 실제 풍량 명령으로 단수가 바뀌었다. 최신 재현 시험은 같은 보관 원음이고, 새 남현지 실발화25회를 추가한 것이 아니다. 이전14/25 기록은 [기존 집계](2026-10-24-nfr25-live-result.md)로 별도 보존한다.

WAV→Core 시험은25문항에 대응한24개 송신 보고와 Core state의24개 변화를 순서대로 대조했다. NONE 보고를 명령 성공으로 세지 않고, 수락 여부와 실제 기기 동작 완료도 구분한다. 실시간 재생은25문항 모두 전사가1개씩 있었으나 대상·활성어·동작 전사가 달라져7개가 정답 intent/value에 도달하지 못했다. 빠른 처리만으로 인식 정확도가 해결됐다고 판단하지 않는다.

## 원음 끝 기준 지연

전체 원음 실시간 재생은 다음과 같다. 이 시험은 Core 발행을 끈 별도 시험이므로 Core 수락20건과 합쳐 공식 성공률을 만들지 않는다.

|지연 지표|결과|
|---|---:|
|최소|0.759초|
|중앙값|1.155초|
|p95|1.326초|
|최대|1.338초|
|끝 경계 오차를 반영한 보수적 최대|1.588초|

입력 PCM을 원본과 상호상관으로 정렬했고25구간의 파형 상관계수는 모두1.0이었다. VAD 추정 종료 시각 대신 원음500~4000Hz 에너지를20ms 창·10ms 간격으로 분석하고25개 곡선의 끝 경계를 확인했다. 사람의 음소 청취 주석이 아닌 음향 신호 추정임을 명시하며, 종료 경계에-250/+100ms 범위를 두었다. 같은 Pi5 monotonic clock으로 원음 위치와 intent 시각을 비교했다. 이 범위에서25개 모두3초 이내였지만, 정답 판정은18개다.

## 제외·중단한 시도와 한계

첫 가상 입력 시도는 장치가 잘못 복원되어 중단하고 성적에서 제외했다. 이후 물리 장치가 없는 별도 PulseAudio 서버로 입력 경로를 확인했다.

가상 입력에서 실제 발행을 시도한 별도 실행은 첫 명령 수락 뒤 시각 검사에서 중단됐다.10ms 버퍼의 시작 PTS가 clock보다109µs 앞선 사례였다. 시각 보호 검사를 완화하거나5초 기한을 늘리지 않았다. 이 부분 실행과 정리 명령은25회 성적에 넣지 않았다. 따라서 WAV Core 수락과 실시간 지연을 나누어 검증한 것이며, 실제 ReSpeaker 입력·발행·Core 수락·원음 끝 지연이 같은 실행에서 검증됐다고 주장하지 않는다.

사용자는 이번 범위를 보관 원음 검증으로 지정했다. 추가 실발화는 진행하지 않는다. 고정 구성의 부정36·실제 주변음300초와 공식 지정 화자25회, PM·계약 담당·요청 리뷰어 승인 및 CI 완료 조건은 유지한다. Draft 해제·병합·#62 종료·G5 발행 허용을 이 보고서로 선언하지 않는다.

이 문서는 집계·방법·실행본 해시만 공개한다. 개별 전사·문항 시각·Core 원문·원음·기기 식별정보·개인 작업 경로는 로컬에 보존한다.
