## 커패시터가 하던 일

매트릭스 전원(5V–GND) 사이에 다는 1000 µF 커패시터는 두 가지를 막습니다 [문서: Adafruit NeoPixel Überguide 「Best Practices」].

1. **켜는 순간 전압이 튀는 것** — 전원이 들어오는 순간 선의 인덕턴스 때문에 전압이 순간적으로 치솟아 **첫 번째 LED**가 손상될 수 있음
2. **LED가 한꺼번에 켜질 때 전압이 꺼지는 것** — 전류가 갑자기 늘면 전압이 순간적으로 떨어져 색이 깨지거나 ESP32가 재부팅될 수 있음

키트(MechaSolution 아두이노 키트)에 전해 커패시터가 없어서 당장 구할 수 없으므로, 아래 절차로 두 위험을 대신 줄입니다.

---

## 연결 순서 (매번 지킬 것)

| 순서 | 할 것 | 막는 위험 |
|---|---|---|
| 1 | **충전기를 콘센트에서 뺀 상태**로 시작 | 전기가 흐르는 선에 매트릭스를 꽂는 순간이 가장 위험 (1번) |
| 2 | **GND부터** 연결 — 충전기 GND ↔ 매트릭스 GND ↔ ESP32 GND | 데이터선이 GND보다 먼저 닿으면 LED 입력이 상할 수 있음 |
| 3 | 5V 연결 — 충전기 5V → 매트릭스 **보조 전원선** 빨강 | ESP32 5V 핀으로 주지 않음 (LED 256개) |
| 4 | 데이터 연결 — ESP32 GPIO → **220 Ω** → 매트릭스 입력 커넥터 `DIN` | 첫 LED 데이터 입력 보호 (키트의 220 Ω 사용) |
| 5 | **마지막에** 충전기를 콘센트에 꽂음 | |

끌 때는 반대로 **충전기를 먼저 콘센트에서 뽑고** 선을 뺍니다.

## 배선 요약

```text
충전기 5V ────────────────────────▶ 매트릭스 보조 전원선 (빨강)
충전기 GND ──┬────────────────────▶ 매트릭스 보조 전원선 (검정)
             └──▶ ESP32 GND
ESP32 GPIO ──[ 220 Ω ]────────────▶ 매트릭스 입력 커넥터 DIN
                                    (출력 커넥터 DOUT은 사용 안 함)
```

- 충전기: **5V 2A 이상**. 1A짜리면 아래 전류 제한을 800 mA로 낮춤
- 전원선(충전기 ↔ 매트릭스)은 **짧게**. 길수록 1·2번 위험이 커짐
- 안 쓰는 USB 케이블을 잘라 쓰면 보통 빨강 = 5V, 검정 = GND. 싼 케이블은 색이 다를 수 있으니 가능하면 멀티미터로 확인

## 펌웨어에서 할 것

전류가 갑자기 튀지 않게 **켜자마자 전부 끄고, 전류 상한을 걸고, 밝기를 천천히 올립니다.** FastLED 기준 예시 [문서: FastLED `setMaxPowerInVoltsAndMilliamps`, `clear`, `setBrightness`]:

```cpp
#include <FastLED.h>

constexpr int kDataPin = 18;       // 실제 연결한 GPIO로 바꿀 것
constexpr int kNumLeds = 256;      // 16 × 16
CRGB leds[kNumLeds];

void setup() {
  FastLED.addLeds<WS2812B, kDataPin, GRB>(leds, kNumLeds);
  FastLED.setMaxPowerInVoltsAndMilliamps(5, 1500);  // 충전기 1A면 800
  FastLED.setBrightness(0);
  FastLED.clear(true);                              // 켜자마자 전부 소등
  for (int b = 0; b <= 76; b += 4) {                // 0 → 약 30 % 까지 천천히
    FastLED.setBrightness(b);
    FastLED.show();
    delay(20);
  }
}
```

- 밝기 상한 30 %는 설계서 §4.4(D-27) 기준. 검은 반투명 아크릴 아래에서 너무 어두우면 PM과 조정
- 빨강·주황 위주로 쓰면 LED 한 개당 한 색만 켜져 전류가 적음
- 데이터 핀 번호(`kDataPin`)는 쿡탑 ESP32 배선이 정해지면 바꿈

## 이상 증상과 대응

| 증상 | 의심 | 대응 |
|---|---|---|
| 첫 번째 LED만 안 켜지거나 색이 이상, 나머지는 정상 | 첫 LED 손상 (1번 위험) | 첫 LED를 건너뛰도록 데이터선을 두 번째 LED 입력으로 옮기거나 패널 교체. 이후 반드시 커패시터 추가 |
| 밝게 켤 때 색이 깨지거나 깜박임 | 전압 강하 (2번 위험) | 전류 상한·밝기 낮추기, 전원선 짧게 |
| 밝게 켤 때 ESP32가 재부팅 | 전압 강하가 ESP32까지 영향 | ESP32 전원을 매트릭스와 분리(GND만 공통), 밝기 낮추기 |
| 아무것도 안 켜짐 | 입력/출력 커넥터 반대, GND 미공통 | 입력(`DIN`) 쪽 커넥터인지, GND가 ESP32와 이어졌는지 확인 |

## 커패시터를 구하면

- **1000 µF, 내압 10 V 이상** 전해 커패시터 1개
- 매트릭스 보조 전원선의 5V–GND 사이, **매트릭스에 최대한 가깝게**
- **극성 주의**: 다리가 긴 쪽(+)을 5V, 몸통에 띠(−)가 있는 쪽을 GND. 반대로 달면 터질 수 있음
- 달고 나서도 위 연결 순서는 그대로 지키는 게 안전
