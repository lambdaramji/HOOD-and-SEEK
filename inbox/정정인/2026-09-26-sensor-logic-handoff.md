## 1. 열화상

### 판정 지표는 `max − median`

- CSV의 `delta` 열은 **`p95 − median`** 이라 단계를 구분하지 못합니다 — 45도 `8.47`, 50도 `8.46`으로 같음 [실측]. 핫팩 고온부가 프레임의 5%보다 작아 p95가 열원을 못 잡는 것으로 추정.
- 09-02 임계값(8/16/22)도 `max − median`으로 산출된 값입니다 [실측, 09-02 CSV 대조].

### 핫팩 5단계 [실측]

안정 구간(30초간 `max` 변동 ≤ 0.6°C)만 사용. 데이터: [`box_hotpack.csv`](box_hotpack.csv)

| 설정 | `max` | **`max − median`** 평균±σ | 인접 단계와 간격 |
|---|---|---|---|
| 45도 | 42.2°C | **13.9** ± 0.2 | — |
| 50도 | 45.6°C | **17.2** ± 0.1 | +2.5 |
| 55도 | 49.4°C | **21.2** ± 0.3 | +2.7 |
| 60도 | 53.1°C | **24.8** ± 0.2 | +2.6 |
| 65도 | 57.0°C | **28.6** ± 0.1 | +3.3 |

- **경계 16**은 45도(최대 14.34)와 50도(최소 16.82) 사이, **경계 22**는 55도(최대 21.74)와 60도(최소 24.36) 사이 → 새 배치에서도 유효.
- 핫팩 가열 중 최대 상승률 **0.18 °C/s** → 급상승 기준 `TH_RISE 10.0`과 두 자릿수 차이. 실제 화염의 상승률은 미측정.

### 빈 상태 · 사람 [실측]

데이터: [`box_off_person.csv`](box_off_person.csv)

| 상태 | `max − median` | `hot_px` |
|---|---|---|
| 핫팩 없음 | **11.9** | 63~81 |
| 사람이 요리 자리에 섬 | **11.5** | 78~99 |
| 45도 핫팩 (참고) | 13.9 | 69~78 |

1. **인덕션 역할 디스플레이 1이 약 40°C로 보여서, 아무것도 없어도 11.9.** 정상 상한 8을 그대로 쓰면 항상 「관심」입니다.
2. **사람은 온도 단계를 올리지 않습니다.** 배경(`median`)만 오르고 `max`는 그대로라 값이 오히려 내려감.
3. **`hot_px`로는 사람과 열원을 구분할 수 없습니다** (사람 78~99 vs 핫팩 69~92). 사람 여부는 카메라 관측으로.

### 합의 필요 — 정상 상한

| 안 | 내용 | 비고 |
|---|---|---|
| A. 고정값 12.5로 상향 | 정상 < 12.5 / 관심 12.5~16 / 주의 16~22 / 경고 > 22 | 빈 상태(최대 12.05)와 45도(최소 13.73) 간격이 1.7°C뿐 |
| B. 기동 시 기준 프레임 | 시작 때 빈 화면을 저장하고 픽셀별 상승분으로 판정 | 디스플레이 발열 상쇄. Pi4 관측 로직 변경 |
| **C. 디스플레이 영역 제외** (제안) | 디스플레이 픽셀을 판정 영역에서 빼고 자극 자리만 판정 | 열원을 디스플레이 **옆**에 두는 배치에서만 성립. 검증에는 픽셀 프레임 저장 필요 |

## 2. SPS30

### 현행 규칙은 연기를 못 잡습니다 [실측]

현행: `tsize < 0.60` AND `coarse < 1.20` AND `fine > 0.90`. 인센스 연기에서 **`fine` 최대 0.860**, 99행 중 3조건 충족 **0행**. `fine`은 평소 0.860 고정, 연기 0.79~0.86, 수증기 0.19~0.86으로 판별력이 없습니다. `coarse`도 연기 중 1.204가 나와 조건이 깨졌습니다.

### 입자 크기(`tsize`)가 연기와 수증기를 가름 [실측]

데이터: [`box_incense.csv`](box_incense.csv), [`box_mist_1.csv`](box_mist_1.csv), 09-02 [`mist.csv`](mist.csv) · [`mist_2.csv`](mist_2.csv)

| | PM2.5 | `tsize` |
|---|---|---|
| 평소 공기 | 17~28 | 0.42~0.46 |
| 인센스 연기 | 78~1849 | **0.39~0.44** |
| 가습기 수증기 (시연 박스) | 51~1903 | **0.46~1.51** (대부분 0.5 이상) |

- 평소 공기와 연기는 `tsize`가 겹칩니다 → **농도 상승으로 먼저 거르고** `tsize`로 연기/수증기를 가릅니다.
- 수증기가 **처음 도달한 2초**는 `tsize 0.457`로 연기처럼 보입니다 → **연속 조건 필요**.

### 규칙 후보 비교 [실측 데이터로 계산]

판정 = PM2.5 조건 AND `tsize < T`가 **연속 N행**(약 1행/초). 오탐 = 수증기 파일 3개(`box_mist_1` / `mist` / `mist_2`)에서 판정이 난 행 수.

| PM2.5 조건 | T | N | 연기 첫 판정 (도달 후) | 수증기 오탐 |
|---|---|---|---|---|
| > 35 | 0.60 | 1 | 즉시 | 16 / 4 / 3 |
| > 50 | 0.49 | 1 | 즉시 | 2 / 2 / 0 |
| > 50 | 0.49 | 3 | +2초 | **0 / 0 / 0** |
| **기준선 + 50** | **0.49** | **3** | **+2초** | **0 / 0 / 0** |

### 제안 규칙 (제안, 합의 필요)

```text
입력 (Pi4 관측):  pm25_ug_m3, tsize_um
기준선:          기동 후 30초 PM2.5 중앙값
연기 후보:        pm25 > 기준선 + SMOKE_PM_RISE   AND   tsize < SMOKE_TSIZE_MAX
연기 확정:        연기 후보가 SMOKE_CONFIRM_ROWS 행 연속
수증기:           pm25 > 기준선 + SMOKE_PM_RISE   AND   tsize >= SMOKE_TSIZE_MAX
```

| 상수 | 임시값 | 근거 |
|---|---|---|
| `SMOKE_PM_RISE` | 50 µg/m³ | 기준선+30은 09-02 수증기에서 오탐 1행, +50은 0행 |
| `SMOKE_TSIZE_MAX` | 0.49 µm | 연기 최대 0.438 → 여유 0.05 |
| `SMOKE_CONFIRM_ROWS` | 3 | 수증기의 저-`tsize` 구간이 2행 |
| 해제 조건 | 미정 | 회복 구간 반복 측정 필요 |

- 고정값(`PM2.5 > 50`) 대신 **기준선 대비**를 권하는 이유: 평소 공기와 연기의 `tsize`가 겹쳐 사실상 농도만으로 둘을 가르므로, 실내 PM2.5가 50을 넘는 날(미세먼지 나쁨)에는 고정값이 오탐합니다 [추정 — 확인 방법: PM2.5 높은 날 평소 공기 로깅].
- 연기·수증기가 확정됐을 때 팬 단계와 `SafetyLevel`을 어떻게 할지는 정책 결정입니다.

### 측정 시 주의

PM2.5가 **1,000을 넘으면 기록이 몇 초씩 빠집니다** (5곳 모두 1,000 초과 직후) [실측]. SPS30 질량 농도 사양 범위가 0~1,000 µg/m³라 그 이상은 사양 밖입니다 [문서: Sensirion SPS30 데이터시트]. 판정에는 문제가 없지만(1,000 초과 구간의 `tsize`는 연기 0.41~0.44, 수증기 0.99~1.51로 뚜렷함), 공백 동안은 새 관측이 없다는 점을 heartbeat 처리에서 고려해야 합니다.

## 재현 방법

규칙 후보 비교표를 다시 계산하는 코드입니다. 저장소 루트에서 실행합니다.

```bash
python3 - <<'EOF'
import csv, statistics as st
def load(p):
    out = []
    for r in csv.DictReader(open(p)):
        try: out.append({k: float(v) for k, v in r.items() if k})
        except (TypeError, ValueError): pass
    return out
d = "inbox/정정인/"
smoke = load(d + "box_incense.csv")
steam = [load(d + f) for f in ("box_mist_1.csv", "mist.csv", "mist_2.csv")]
def judge(rows, rise=50, t_max=0.49, n=3):
    base = st.median(r["pm25"] for r in rows if r["sec"] < 30)
    streak, first, hits = 0, None, 0
    for r in rows:
        streak = streak + 1 if (r["pm25"] > base + rise and r["tsize"] < t_max) else 0
        if streak >= n:
            hits += 1
            first = r["sec"] if first is None else first
    return first, hits
print("연기 첫 판정(초):", judge(smoke)[0])
print("수증기 오탐 행:", [judge(m)[1] for m in steam])
EOF
```

열화상 단계 표는 가이드 C-3의 스크립트에서 `COL`을 쓰지 말고 `max`와 `median` 열로 `max − median`을 계산합니다.
