## 열화상 — MLX90640

| 항목 | 값 |
|---|---|
| I2C 주소 | `0x33` |
| 통신 | I2C 100kHz (Pi4 GPIO2/3) |
| 해상도 | 32×24 픽셀 |
| 방사율 | 0.95 |
| 주요 지표 | `delta(max−median)`, `hot_px`, `hotmean`, `rise` |

#### 확정 임계값 (ΔT = max − 배경) [실측 2026-09-02]

| 단계 | ΔT | 절대온도 (`max`) |
|---|---|---|
| 정상 | < 8 | < 34°C |
| 관심 | 8 ~ 16 | 34 ~ 41°C |
| 주의 | 16 ~ 22 | 41 ~ 49°C |
| 경고 | > 22 | > 49°C |

#### 보정식 (현재 배치 조건 한정)

```
실제온도 = (측정 − 11.29) / 0.634    R² = 0.998
```

> ⚠️ 배치 변경 시 재측정 필요.
> 사람 진입 시 `hot_px` 사용 (핫팩 12~28px vs 사람 101~185px).

## 미세먼지 — SPS30

| 항목 | 값 |
|---|---|
| I2C 주소 | `0x69` |
| 시리얼 | `1C451D7CCF1D5D86` |
| 펌웨어 | `2.3` |
| 통신 | I2C (SDA/SCL 3.3V 직결) |
| VDD | **5V (Pi4 5V핀)** |
| SEL 핀 | **GND 연결 필수** (미연결 시 UART 모드) |
| 커넥터 | JST ZH 케이블 별도 |

#### 연기/수증기 판별 임계값

| 지표 | 임계값 | 연기 조건 |
|---|---|---|
| `TH_TSIZE` | 0.60 | < 0.60 이면 연기 쪽 |
| `TH_COARSE` (PM10/PM2.5) | 1.20 | > 1.20 이면 수증기/먼지 |
| `TH_FINE` (PC0.5/PC10) | 0.90 | > 0.90 이면 연기 쪽 |

> 세 조건 **모두** 만족 시 연기 판정. [실측 2026-09-02] 수증기 오탐 0건.
> ⚠️ **세로 배치 무효** — 가로 배치 필수. 시연 가습기는 **1단** (2단 이상 PM2.5 포화).

## 팬 제어 — ESP32 + IRLZ44N

#### ESP32

| 항목 | 값 |
|---|---|
| 전원 | USB 허브 (전원 + serial CDC 겸용) |
| PWM 핀 | GPIO26 |
| PWM 주파수 | 25,000 Hz / 8-bit |
| Heartbeat timeout | 3,000 ms |
| 통신 속도 | 115,200 baud |

#### MOSFET 회로 (IRLZ44N)

| 핀 | 연결 |
|---|---|
| 게이트 | ESP32 GPIO26 |
| 소스 | GND 공통 |
| 드레인 | 팬(−) |
| 팬(+) | 외부 5V (USB 허브 분기) |

> ⚠️ GND는 ESP32 · MOSFET · 팬 전원 모두 공통 연결 필수.

#### PWM Duty

| 단계 | Duty |
|---|---:|
| 0 (정지) | 0 |
| 1 (약풍) | 85 |
| 2 (중풍) | 170 |
| 3 (강풍 / fail-safe) | 255 |

#### Serial 프로토콜

| 방향 | 형식 |
|---|---|
| Pi5 → ESP32 | `FAN <0-3>\n` |
| ESP32 → Pi5 | `ACK FAN <0-3>\n` |
| ESP32 → Pi5 | `FAILSAFE timeout FAN 3\n` (3초 두절 시) |

> 부팅 즉시 팬 3단. 허브 급전으로 Pi5 다운 시에도 팬 유지.
