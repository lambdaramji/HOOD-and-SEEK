## 하드웨어 구성

| 부품 | 모델 / 스펙 | 연결 |
|---|---|---|
| **센서 노드** | Raspberry Pi 4 · ATLAS Headless | IP `<Pi4 IP>` |
| **게이트웨이** | Raspberry Pi 5 (8GB) · ATLAS Video | IP `<Pi5 IP>` |
| **카메라** | LifeCam HD-3000 · JPEG 640×480 30fps | Pi4 USB (`/dev/video0`) |
| **열화상** | MLX90640 · 32×24px · I2C `0x33` | Pi4 GPIO2/3 |
| **미세먼지** | SPS30 · VDD 5V · SEL→GND 필수 · I2C `0x69` | Pi4 GPIO2/3 |
| **RTC** | DS3231 · CR2032 · I2C `0x68` | Pi4 GPIO2/3 (hwclock 유지) |
| **팬 컨트롤러** | ESP32 DevKit · GPIO26 PWM | USB 허브 경유 → Pi5 serial (CDC) |
| **팬 드라이버** | IRLZ44N MOSFET · 외부 5V | GPIO26 → 게이트 |
| **팬** | 5V 블로워 | IRLZ44N 드레인 |

**I2C 버스 주소 충돌 없음**: `0x33` / `0x68` / `0x69` · 배선 ≤10cm

**열화상 4단계 임계값** (ΔT = max − 배경)

| 단계 | ΔT | 절대온도 |
|---|---|---|
| 정상 | < 8 | < 34°C |
| 관심 | 8~16 | 34~41°C |
| 주의 | 16~22 | 41~49°C |
| 경고 | > 22 | > 49°C |

보정식: `실제온도 = (측정 − 11.29) / 0.634` (R²=0.998, 현재 배치 조건 한정)

**SPS30 연기 판별 조건** (세 조건 모두 만족 시 연기)

| 지표 | 연기 조건 |
|---|---|
| `tsize` (평균 입자크기) | < 0.60 |
| `coarse` (PM10/PM2.5) | < 1.20 |
| `fine` (PC0.5/PC10) | > 0.90 |

## 멘토 확인 요청

- SPS30 **SEL 핀 → GND 연결 없이도 I2C 동작했는가?** 현재 미확인 상태. 모드 혼동 가능성 있음.
- 열화상 **60도 구간이 55도와 겹치는 이유** — 핫팩 특성인지 측정 오류인지 불명확. 데이터 공유 후 판단 요청.
- 현재 MLX90640 보정계수(`0.634`)는 **이번 배치 조건에서만 유효**. 실제 후드 설치 후 재보정 필요한지 판단 요청.
