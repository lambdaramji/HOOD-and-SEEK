# 음성 명령 결과·미지원 안내 WAV 12개 — Q3 E2 후보

「요청을 받았어요」를 음성으로 알리지 않는다. Core 최종 설정과 장치 ACK가 확인된 결과를 말한다(사용자 요청, 2026-10-26, #172). 예: 「후드를 강풍으로 설정했어요」「인덕션이 꺼졌어요」.

**기존 11개 연결은 #176에 있으며, 이 PR은 그 위에서 IND_SET 결과 연결과 미지원 안내 1개를 추가한다. 운영 앱은 아직 교체하지 않았다.** #169의 기동음·터치음·WARNING은 별도 범위다.

## 재생 조건 — Flutter 담당 검토

- accepted 하나로 완료 음성을 내지 않는다. 최신 음성 결과·유효한 Core state·해당 장치 ACK와 최종 단수를 확인한다. 타임아웃·끊김·응답 미확인에는 완료 문구를 내지 않는다.
- 후드는 FAN_SET 값 또는 FAN_OFF의 0과 `fan.requested`가 같은지 확인한다. 실제 단수가 요청보다 높고 `max(fan.min, fan.requested)`에 일치하는 안전 보정 결과면 `RESULT_FAN_MIN_N`을 사용한다. 「껐어요」라고 잘못 안내하지 않는다.
- 일반 후드 결과는 실제 0/1/2/3단으로 고르고, 인덕션 결과는 장치 ACK가 있는 최종 0/1/2/3단으로 고른다. 올리기·내리기 문구 대신 최종 설정 문구를 재사용한다.
- 장치 ACK가 확인한 설정 결과를 뜻한다. 팬 회전수·가열 전류를 따로 계측한 결과는 아니다. 쿡탑은 프로젝트의 ESP32 시뮬레이터다.
- 경고·끊김·거부 안내가 우선이며 결과 음성은 이를 중단하지 않는다. 과거 결과를 큐에 쌓았다가 늦게 읽지 않는다.
- 현재 `state.voice`에는 요청 식별자가 없어 같은 결과가 연달아 오면 새 요청인지 구분할 수 없다. 자동 제어와 동시 요청의 대응도 담당 검토가 필요하다. 이번 음원 제작이 이 계약 한계를 해결한 것은 아니다.

## 제작·검사

- AI 합성 음성. 기존 Q3 E2와 같은 자체 합성 참조음 및 Qwen3-TTS 1.7B Base 8bit를 재사용했다. 사람 목소리 녹음·Typecast는 사용하지 않았다.
- 모델·참조 해시·seed·파일 해시·형식은 `manifest.json`에 기록했다. 모델 라이선스는 [기존 Apache-2.0 전문](../MODEL-LICENSE.txt), 음색 제작 이력은 [기존 음원 README](../README.md)를 따른다.
- 11개 모두 48 kHz·mono·PCM16·클리핑 0. 파일 해시는 `SHA256SUMS`로 확인한다. −19 LUFS 목표 정규화 후 말끝을 약하게 감쇠했다.
- Mac SenseVoice 전체 파일 자동 전사에서 공백·문장부호 제외 10/11 일치. 나머지는 후드의 모음 표기 차이다. 자동 전사는 청취 승인이나 실기 ReSpeaker 재유입 합격이 아니다.
- 10/26 원본 11개×10회 실제 ReSpeaker 재유입에서 **NONE 포함 후보 0·송신 0**, 입력·출력 경로 110/110을 확인했다. ASR 종료 집계 94회, 보존 개별 기록 93회 DROP·1회 미보존, 최대 발화 초과 7건이다. [집계·보존 한계](../../../../inbox/이수현/2026-10-26-voice-result-feedback.md)를 함께 기록한다.
- 기존11개 PM 청취 OK·110회 실기는 #173 기록이다. 새 RESULT_UNSUPPORTED의 PM 청취는 #186에서 승인됐고 마이크 재유입은 미실시이며 이전110회에 포함시키지 않는다. 이 PR의 새 음성 파서 구성도 현장 부정 시험 전이다.


## 미지원 안내 추가 — 사용자 요청 2026-10-26

- 새 Core 결과가 `last_intent=NONE`·`accepted=false`·`reason=NO_INTENT`로 바뀌고 같은 state에 alert가 없을 때만 RESULT_UNSUPPORTED를 한 번 재생한다. 시작 시 과거 결과, 호출어 없는 DROP, VAD/ASR 실패, 다른 거부 사유에는 재생하지 않는다.
- 기존 result 경로로 재생해 경고를 끊지 않으며 경고 중에는 생략한다. 요청 ID가 없어 동일 NONE 결과가 연속되면 새 요청을 구분하지 못하는 한계는 그대로다.
- 기존 자체 합성 Q3 E2 참조·모델·라이선스를 재사용했다. 실제 사람 녹음과 Typecast를 사용하지 않았다. 새 파일도 AI 합성 음성이다. 나머지11개 WAV는 바이트 단위로 보존했다.
